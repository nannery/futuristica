# Futuristica

Static rebuild of futuristica.yolasite.com: plain HTML and CSS, hosted on GitHub Pages.

- `index.html`, `portfolio.html`, `products.html`, `contact.html`, `style.css`
- `images/` is filled by the one-time **Import from Yola** workflow, which also
  saves the original Yola pages to `_yola/` for reference.
- The contact form posts to Formspree; set `FORM_ID` in `contact.html`.
